Wikidata backfill

Ship register

Looks up every gap in the register on Wikidata and lists the work in three piles: fields it can fill in on its own, photos it can license properly, and names only a human can resolve.

Scanning writes nothing. Every write on this page is a button press, and each button does exactly what it says the moment you press it. Only empty fields are ever filled, so anything curated by hand survives a re-run.

Matched on a number, so the ship is the same one — an IMO or an MMSI identifies a hull, which is why these need no judgement. Untick anything you would rather not have. Every ticked row is re-checked against the register as it is written, so a field somebody filled in meanwhile is skipped rather than overwritten.

The cached photos are copyrighted stills from an image search. Where Wikidata knows the ship by number, Commons has one under a licence that permits the use, with an author to credit. Offered one by one: the free file is not always the better picture. Replacing keeps the old one on file — it just stops being the one shown.

Trips that name a ship the register does not know. Matched on the name alone, so this is a lead and not a fact — several real ships share a name. Assigning creates the ship and rewrites those trips to point at it.
